# DeepSeek Harness Cockpit - Windows 冒烟测试手册

## 1. 运行前准备与前置环境
- 操作系统: Windows 10 / Windows 11 (x64)
- Node.js >= 20.0.0 (`node -v`)
- pnpm >= 9.0.0 (`pnpm -v`)
- Git (`git --version`)

## 2. 测试步骤与验收标准

### 用例 1: 首次启动与基础界面渲染
- **操作**: 运行 `npm start` 启动应用。
- **预期**:
  - 窗口正常打开，尺寸为 1080x750，左侧展示侧边栏，顶部为应用 Logo，底部为全局状态栏；
  - 默认打开“仓库同步”页面；
  - 任务栏图标为粉紫渐变鲸鱼，而非 Electron 默认图标；
  - 状态栏显示“仓库: 未配置”，“Web: 已停止”。

### 用例 2: 本地 Harness 目录选择与状态巡检
- **操作**: 点击“浏览目录”，选择一个有效的 `deepseek-harness` 仓库路径。
- **预期**:
  - 路径输入框自动填充，配置持久化至 `%APPDATA%\DeepSeek-Cockpit\config.json`；
  - Git 状态看板展示当前分支、HEAD 提交哈希、上游分支与落后/领先提交数；
  - 若工作区存在改动，显示黄色警告框并禁用“安全同步”按钮；
  - 若工作区干净且落后上游，启用“安全同步”按钮。

### 用例 3: 安全 Git 同步 (Fast-Forward Only)
- **操作**: 点击“检查更新 (Fetch)”，随后点击“安全同步 (Fast-Forward)”。
- **预期**:
  - 执行安全 fetch，终端与提示输出同步进度；
  - 仅快进拉取更新，绝不破坏本地未提交修改或进行强制合并。

### 用例 4: 环境预检与依赖编译
- **操作**: 切换至“Web 服务”页面，查看预检列表，并点击“安装依赖并编译”。
- **预期**:
  - 预检列表各项绿色打钩；
  - 弹出确认提示框后执行 `pnpm install` 与 `pnpm run build`，终端实时滚动输出构建日志。

### 用例 5: Web 启动、探活与浏览器直连
- **操作**: 保持默认端口 3080，勾选“自动打开浏览器”，点击“启动 Web 服务”。
- **预期**:
  - 状态变为“正在启动...”，终端打印 `pnpm dsh web --port 3080` 输出；
  - 内置 HTTP 探活成功后，状态指示灯转为绿色“运行中 (:3080)”；
  - 系统默认浏览器自动打开 `http://127.0.0.1:3080`；
  - 点击“停止服务”或“重启服务”均能正确释放与重新绑定端口。

### 用例 6: 插件管理、市场浏览、构建审批与卸载
- **操作**: 切换至“插件管理”页面：
  1. 切换至“插件市场”，在分类标签中点击“UI 增强”或“工具与能力”进行筛选，在搜索框输入关键词；
  2. 点击某个插件的“安装”按钮（支持 npm 模块与 Git 仓库）；
  3. 切换至“安装自定义插件”，输入 npm/Git/本地路径预览命令后安装；
  4. 若出现未审批的构建脚本，点击“授权编译”；
  5. 点击“已装插件”列表中的“卸载”按钮。
- **预期**:
  - 变动前自动在 `%APPDATA%\DeepSeek-Cockpit\backups\` 生成备份；
  - 插件市场正确展示 12 大分类与 800+ 插件，支持分页、排序与即时搜索；
  - 命令安全执行，安装/卸载后列表自动刷新；
  - 绝不静默全局批准未知插件。

### 用例 7: `cordis.patch.yml` 补丁编辑与自动回滚
- **操作**: 切换至“编辑 Patch 补丁”子标签：
  1. 输入故意写错的 YAML 格式并点击保存；
  2. 修正为正确 YAML 并保存。
- **预期**:
  - 错误 YAML 立即被前端语法校验拦截并提示行号，文件不被覆盖；
  - 有效 YAML 写入后调用 `dsh --dump-config` 校验，校验通过提示保存成功；若 Harness 解析失败，自动利用 `.bak` 恢复原配置。

### 用例 8: 系统托盘与最小化收纳
- **操作**:
  1. 启动应用后，查看任务栏右下角通知区域；
  2. 点击窗口标题栏的最小化按钮；
  3. 单击左键点击托盘图标；
  4. 点击标题栏关闭按钮 ×，再右键托盘图标选择“显示主界面”。
- **预期**:
  - 通知区域出现粉紫渐变鲸鱼托盘图标，悬停显示提示文字 `DeepSeek Harness Cockpit`；
    （Windows 11 默认把首次出现的托盘图标收进「显示隐藏的图标」浮出层，需展开后查看或拖出来固定，这是系统行为不是缺陷）
  - 最小化后窗口从任务栏消失并收进托盘，不占用任务栏位置；
  - 左键单击托盘图标窗口原样恢复并获得焦点（尺寸与页面状态不丢失）；
  - 点击 × 不退出应用，仅隐藏窗口；通过托盘菜单可再次唤出。

### 用例 9: 优雅关停
- **操作**: 在 Web 运行状态下右键托盘图标，选择“退出”。
- **预期**:
  - 触发 `before-quit` 钩子，后台托管的 Node/pnpm 进程树被彻底杀灭，不遗留孤儿后台进程；
  - 托盘图标随进程一并消失，不留下僵尸图标。
